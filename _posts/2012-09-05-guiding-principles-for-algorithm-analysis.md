Three guiding principles:

1. Worst case analysis: Requires&nbsp;no assumptions on where input comes
from. Also&nbsp;no domain knowledge needed.

Theres also average case analysis/benchmarks.&nbsp;This requires domain
knowledge

Not much attention to constant factors, lower-order terms.

Asymptotic analysis - focus on large input sizes.

What is a &quot;fast&quot; algorithm?

One whose worst-case running time grows slowly&nbsp;with input size

Holy grail: achieve linear running time (or close to it)
